UPLOAD TO GITHUB:
1. Open https://github.com/inkdesign007-del/inkdesign-studio-website
2. Click Add file > Upload files.
3. Upload/replace index.html, styles.css, script.js, CNAME, robots.txt, sitemap.xml.
4. Upload the full assets folder and its image files (GitHub's browser uploader accepts drag-and-drop of the files; make sure they land inside assets/).
5. Commit changes to the main branch.
6. Wait 1–3 minutes, then open https://inkdesignstudio.co.in/ and hard-refresh with Ctrl+F5.
